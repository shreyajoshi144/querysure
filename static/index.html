01The problem

An AI can answer a question. The hard part is trusting the answer.

Natural-language analytics goes wrong when a model guesses at your schema, writes SQL nobody checked, or hands back a number with no working.

QuerySure grounds each question in your connected schema and semantic layer, validates the SQL before it runs, scores data reliability, and records how the answer was produced. Answers from documents must cite the passages they use, or they are not shown.

iSchema and semantic groundingThe model sees the structure and meaning of your data, not a guess at it.
iiSQL validation and safe executionGenerated queries are checked at the syntax-tree level and run read-only.
iiiReliability and provenanceData-quality signals and the path behind the answer stay beside the result.

JOIN stores AS s ON s.store_id = o.store_id

04Capabilities

Data, documents and actions, each with a record.

Teams share datasets and documents in workspaces with roles. Every feature gives the model one narrow job and checks its output in code before you see it.

Ask your data

Upload files or connect PostgreSQL, MySQL, a REST API or S3. Questions become grounded, validated, read-only SQL, and every import gets a data-quality report.

Ask your documents

Upload TXT, Markdown, PDF or Word files and chat with an assistant that cites numbered passages. An answer that cites nothing valid is withheld.

Investigate a change

Trend, comparison and breakdown reports run real queries and keep the SQL behind every fact. Possible causes are labelled unverified. Export as HTML or JSON.

Act only with approval

An agent plans with a fixed set of tools. Reading runs at once; syncing a dataset or deleting a document waits for someone with the right role to approve it. Every step is in the audit trail.

06Evaluation

Evaluation is a separate engineering surface.

The evaluation layer separates deterministic correctness from supplementary model-judge signals. DeepEval is supplementary, and synthetic cases expand coverage when generated. Coverage includes SQL validity, execution, result correctness, schema grounding, hallucinated identifiers and rejection or clarification behavior, plus document-retrieval recall and a 36-case adversarial safety suite run against the real controls.

07Questions

Questions worth answering before you connect data.

What is QuerySure?

QuerySure answers questions about your data and documents. Data questions become grounded, validated, read-only queries; document questions get answers that cite their sources. The path behind each result is recorded.

What data can I connect?

You can use the bundled sample database, upload a CSV, JSON, Excel, Parquet or SQLite file, or connect PostgreSQL, MySQL, a REST API or an S3 bucket, with manual or scheduled syncs. Documents can be TXT, Markdown, PDF (text layer) or Word.

Can the AI change my data on its own?

No. Queries are read-only. The agent can propose a change, such as syncing a dataset or deleting a document, but it waits for approval from someone with the right role, and the role is checked again when it runs.

How are document answers checked?

The assistant must cite the passages it used; an answer that cites none of them is withheld. A citation shows where an answer came from, not that it is correct, so check important answers against the source.

Can my team share data?

Yes. Workspaces have viewer, analyst, admin and owner roles, a shared dataset catalog and knowledge hub, and an audit trail of who did what.

Does QuerySure run write queries?

No. The execution path is guarded for read-only analytics; write operations are not part of the query flow.

How does QuerySure validate generated SQL?

Generated SQL passes AST-level and read-only validation before it runs.

What does the reliability information mean?

It surfaces the data-reliability signals QuerySure produces for a result. It is not a guarantee that an answer is correct.

What happens when QuerySure cannot confidently answer?

The pipeline can reject a question or ask for clarification instead of forcing an unsupported result.

Is my data used to train the model?

The product makes no training-use promise on this page. Refer to the privacy policy for how data is handled.

What does the Free plan include?

Free includes 10 analytics queries per day. The server determines your effective plan and daily entitlement.

What happens when I reach my daily query limit?

The server rejects further query execution until the daily window resets at 00:00 UTC.
