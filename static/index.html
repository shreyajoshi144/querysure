01The problem

An AI can answer a question. The hard part is trusting the answer.

Natural-language analytics goes wrong when a model guesses at your schema, writes SQL nobody checked, or hands back a number with no working.

QuerySure grounds each question in your connected schema and semantic layer, validates the SQL before it runs, scores data reliability, and records how the answer was produced.

iSchema and semantic groundingThe model sees the structure and meaning of your data, not a guess at it.
iiSQL validation and safe executionGenerated queries are checked at the syntax-tree level and run read-only.
iiiReliability and provenanceData-quality signals and the path behind the answer stay beside the result.

SELECT s.region, COUNT(o.order_id) AS orders
FROM orders AS o
JOIN stores AS s ON s.store_id = o.store_id
GROUP BY s.region
ORDER BY orders DESC

Generated from the grounded context, not from a guess at your tables.

  • No denied functions, no SELECT *

06Evaluation

Evaluation is a separate engineering surface.

The evaluation layer separates deterministic correctness from supplementary model-judge signals. DeepEval is supplementary, and synthetic cases expand coverage when generated. Coverage includes SQL validity, execution, result correctness, schema grounding, hallucinated identifiers and rejection or clarification behavior.

07Questions

Questions worth answering before you connect data.

What is QuerySure?

QuerySure turns natural-language questions into grounded, validated, read-only analytics queries and records the path behind the result.

What data can I connect?

You can use the bundled sample database or upload a CSV, JSON, Excel or SQLite file. The connected dataset is then used for schema grounding and read-only analysis.

Does QuerySure run write queries?

No. The execution path is guarded for read-only analytics; write operations are not part of the query flow.

How does QuerySure validate generated SQL?

Generated SQL passes AST-level and read-only validation before it runs.

What does the reliability information mean?

It surfaces the data-reliability signals QuerySure produces for a result. It is not a guarantee that an answer is correct.

What happens when QuerySure cannot confidently answer?

The pipeline can reject a question or ask for clarification instead of forcing an unsupported result.

Is my data used to train the model?

The product makes no training-use promise on this page. Refer to the privacy policy for how data is handled.

What does the Free plan include?

Free includes 10 analytics queries per day. The server determines your effective plan and daily entitlement.

What happens when I reach my daily query limit?

The server rejects further query execution until the daily window resets at 00:00 UTC.
